    iter8 API Reference¶

    iter8 is a lazy iterator library for Lua 5.1+ and LuaJIT.

    local Iter8 = require "iter8"

    Constructors¶

    Iter8¶

    Iter8(iter_fn: fun(state: any, control: any), state: any, initial: any, closing: any) → iterator

    The main Iter8 object.

    local Iter8 = require "iter8"

    When called as a function, wraps the return values of a for-loop-compatible, Lua-style iterator such as pairs, ipairs, or string.gmatch. The resulting iterator behaves transparently; that is, it provides the same results when evaluated as if you had directly evaluated the arguments to Iter8.

    Example: 

    local iter = Iter8(pairs(t))
iter = iter:take(3)
for k, v in iter do
    process(k, v)
end

    Iter8.range¶

    Iter8.range(start: integer, finish: integer, step: integer) → iterator
Iter8.range(start: integer, finish: integer) → iterator
Iter8.range(finish: integer) → iterator

    Iterate over a range of integers. start and step are optional, both defaulting to a value of 1.

    Iter8.unfold(seed, fn)¶

    Generate an iterator by (unfolding)[https://en.wikipedia.org/wiki/Anamorphism] using the given seed value and function.

    fn can return either: * both of seed, val; * or simply seed, if seed and val would be the same.

    In some sense, this is the opposite of iterator:fold.

    Parameters:

    Name Type
    seed T
    fn (fun(seed: T): T) | (fun(seed: T): T, any)

    Returns: iterator

    See also: iterator.fold

    Iter8.gmatch(s, pat)¶

    Iterate over matches of the Lua pattern-string pat in the string s.

    Has an alias Iter8.matches.

    Parameters:

    pat string

    Returns: iterator

    See also: Iter8.matches

    Iterate over characters in the string s.

    Parameters:

    Name Type

    Iter8.keys(t)¶

    Iterate over the keys in the table t in an arbitrary order (similar to pairs).

    Parameters:

    Name Type
    t table

    Returns: iterator

    See also: Iter8.values, Iter8.pairs

    Iter8.values(t)¶

    Iterate over the values in the table t in an arbitrary order (similar to pairs).

    Parameters:

    Name Type
    t table

    Returns: iterator

    See also: Iter8.keys, Iter8.pairs, Iter8.ivalues

    Iter8.pairs(t)¶

    Iterate over the keys and values in the table t in an arbitrary order (similar to pairs).

    Has an alias Iter8.table.

    • If you just want the values, use Iter8.values(t) instead.
    • If you just want the keys, use Iter8.keys(t) instead.

    Parameters:

    Name Type
    t table

    Returns: iterator

    See also: Iter8.keys, Iter8.values, Iter8.ipairs, Iter8.table

    Iter8.table¶

    Alias for Iter8.pairs.

    Iter8.ivalues(t)¶

    Iterate over the values in the table t in increasing order (similar to ipairs).

    Has an alias Iter8.list.

    Parameters:

    Name Type
    t table

    Returns: iterator

    See also: Iter8.values, Iter8.pairs, Iter8.list

    Iter8.list¶

    Alias for Iter8.ivalues.

    Iter8.ipairs(t)¶

    Iterate over the indices and values in the table t in increasing order (similar to ipairs).

    • If you just want the values, use Iter8.ivalues(t) instead.
    • If you just want the indices, use Iter8.range(#t) instead.

    Parameters:

    Name Type
    t table

    Returns: iterator

    See also: Iter8.ivalues, Iter8.range, Iter8.pairs

    Iter8.empty()¶

    Returns an empty iterator.

    Returns: iterator

    Iter8.once(...)¶

    Returns an iterator which will: * on the first iteration, produce all the arguments given to Iter8.once; * then finish.

    Parameters:

    Name Type
    ... any

    Returns: iterator

    Iter8.rep(v)¶

    Repeat the given value forever.

    The returned iterator will never finish.

    Parameters:

    Name Type
    v any

    Returns: iterator

    Iter8.cycle(iter)¶

    Returns an iterator which endlessly repeats through the elements of the iterator given as the argument iter.

    Note

    The repetition is accomplished via memoisation of iter's results; as such, if your iterator produces non-deterministic or otherwise changing outputs, you may wish to find another way to achieve this cycling effect.

    The returned iterator will never finish.

    Parameters:

    Name Type
    iter iterator

    Returns: iterator

    Iter8.fn(fn)¶

    Make an iterator from a function which uses return to provide the iteration step values.

    Each time the iterator is stepped, fn will be called, and any values returned will be provided as iteration step values.

    Warning

    This constructor is very low-level, and is intended only for advanced use-cases, when you need to manually implement an iterator.

    Unless you're sure you need this, you should probably use other functions from this library.

    Parameters:

    Name Type
    fn fun(): any

    Returns: iterator

    See also: Iter8.co

    Iter8.co(fn)¶

    Make an iterator from a function which calls coroutine.yield to provide the iteration step values. fn will be passed to coroutine.wrap.

    Each time the iterator is stepped, the coroutine will be resumed, and any values passed to coroutine.yield will be provided as iteration step values.

    Warning

    This constructor is very low-level, and is intended only for advanced use-cases, when you need to manually implement an iterator.

    Unless you're sure you need this, you should probably use other functions from this library.

    Parameters:

    Name Type
    fn fun(): any

    Returns: iterator

    See also: Iter8.fn, coroutine.wrap

    iterator Methods¶

    This section describes the methods available on iterator objects.

    iterator:next()¶

    Return the next value in the iterator, or nil if the iterator is finished.

    Returns: any

    Transformers¶

    iterator:map(fn)¶

    Maps each step of the iterator by passing the values to fn, and replacing the values with the return values of fn.

    Parameters:

    Name Type
    fn fun(...): any

    Returns: iterator

    See also: iterator.flatmap, iterator.filtermap, iterator.trace

    iterator:trace(fn)¶

    Calls fn on each step of the iterator, and returns the iterator unchanged. That is, fn is called on each step of the iterator just for its side-effects.

    Note

    iterator:trace(fn) doesn't evaluate the iterator, and as such, fn will not be called until the iterator is evaluated. If you want to evaluate the iterator straight away, use iterator:foreach(fn).

    Parameters:

    Name Type
    fn fun(...): any

    Returns: iterator

    See also: iterator.map, iterator.foreach

    iterator:filter(pred)¶

    Calls pred on each step of the iterator, and keeps only the steps for which pred returns true.

    Parameters:

    Name Type
    pred fun(...): boolean

    Returns: iterator

    See also: iterator.filtermap

    iterator:filtermap(fn)¶

    Maps each step of iterator by passing the values to fn, and replacing the values with the return values of fn—as long as fn has a value other than nil as its first return value.

    Parameters:

    Name Type
    fn fun(...): any

    Returns: iterator

    See also: iterator.filter, iterator.map

    iterator:flatten()¶

    Turns an iterator of iterators of values into an iterator of values.

    flatten removes exactly one level of nesting.

    Returns: iterator

    See also: iterator.flatmap

    iterator:flatmap(fn)¶

    Maps each step of iterator by passing the values to fn, and replacing the values with the concatenated results of the iterators returned from fn.

    flatmap removes exactly one level of nesting.

    Useful for when you want to use map, but your mapping function may give more than one result.

    Parameters:

    Name Type
    fn fun(...): iterator

    Returns: iterator

    See also: iterator.flatten, iterator.map

    iterator:take(n)¶

    Yields the first n steps of iterator, then ends the iterator.

    If iterator yields fewer than n steps, then the result of take will be equivalent to iterator.

    Parameters:

    Name Type
    n integer

    Returns: iterator

    See also: iterator.drop

    iterator:drop(n)¶

    Skips the first n steps of iterator, then yields the rest of the steps of iterator.

    If iterator yields fewer than n steps, then the result of drop will be equivalent to iterator.empty().

    Parameters:

    Name Type
    n integer

    Returns: iterator

    See also: iterator.take

    iterator:zip(...)¶

    Yields the return values of all component iterators as multiple values on each step of the resulting iterator. Ends when any one of the component iterators ends; that is, the result of zip is the same length as the shortest component iterator.

    All return values of component iterators are included, including multiple return values of component iterators.

    Joins multiple iterators "in parallel". To join iterators "in series", use iterator:chain(...).

    Example: 

    -- prints: "h" 1; "e" 2; "l" 3; "l" 4; "o" 5
Iter8.chars("hello"):zip(Iter8.range(10)):foreach(print)

-- prints: "a" 1 true; "b" 2 true; "c" 3 true
Iter8.chars("abc"):zip(Iter8.range(10), Iter8.rep(true)):foreach(print)

    Parameters:

    Name Type
    ... iterator

    Returns: iterator

    See also: iterator.enumerate, iterator.select, iterator.chain

    iterator:enumerate()¶

    Adds the step index as an extra first value.

    Equivalent to Iter8.range(math.maxinteger):zip(iterator).

    Example: 

    -- prints: 1 "a"; 2 "b"; 3 "c"
for i, v in Iter8.chars("abc"):enumerate() do
    print(i, v)
end

    Returns: iterator

    See also: iterator.zip

    iterator:select(index)¶

    Yields a single return value from each of iterator's steps, ignoring the others. The argument is chosen by index: * If index == 1, the first argument is returned; * If index == 2, the second argument is returned; * etc. In particular, if index is greater than the number of arguments, the returned iterator will be empty.

    iterator:select(index) is analogous to Lua's select(index, ...).

    This might be thought of as a way to "undo" zip.

    Parameters:

    Name Type
    index integer

    See also: iterator.zip

    iterator:chain(...)¶

    Yields all the values of iterator, then all the values of the first argument, then all the values of the second argument, and so forth; until all the iterators are finished.

    Joins multiple iterators "in series". To join iterators "in parallel", use iterator:zip(...).

    Parameters:

    Name Type
    ... iterator

    Returns: iterator

    See also: iterator.zip

    iterator:takewhile(pred)¶

    Yields elements while pred returns true, stopping at the first element for which pred returns false.

    Parameters:

    Name Type
    pred fun(...): boolean

    Returns: iterator

    See also: iterator.dropwhile, iterator.filter

    iterator:dropwhile(pred)¶

    Skips elements while pred returns true, then yields all remaining elements.

    Parameters:

    Name Type
    pred fun(...): boolean

    Returns: iterator

    See also: iterator.takewhile, iterator.drop

    iterator:scan(acc, fn)¶

    Like fold, but yields each intermediate accumulator value rather than returning only the final result.

    Parameters:

    Name Type
    acc A
    fn fun(acc: A, x: T): A

    Returns: iterator

    See also: iterator.fold

    iterator:chunks(n)¶

    Yields non-overlapping chunks of n elements as tables. The final chunk may be smaller than n if the iterator does not divide evenly.

    Parameters:

    Name Type
    n integer

    Returns: iterator

    See also: iterator.windows

    iterator:windows(n)¶

    Yields every overlapping window of n consecutive elements as a table. Produces max(0, length - n + 1) windows.

    Parameters:

    Name Type
    n integer

    Returns: iterator

    See also: iterator.chunks

    iterator:step_by(n)¶

    Yields every nth element, starting with the first.

    step_by(1) is equivalent to the original iterator.

    Parameters:

    Name Type
    n integer

    Returns: iterator

    iterator:intersperse(sep)¶

    Inserts sep between each element of iterator.

    Parameters:

    Name Type
    sep any

    Returns: iterator

    Terminators¶

    iterator:force()¶

    Evaluates iterator for its side effects, throwing away its return values.

    See also: iterator.collect, iterator.foreach

    iterator:foreach(fn)¶

    Evaluates iterator, calling fn on each step's values, and throwing away fn's return values.

    Parameters:

    Name Type
    fn fun(...)

    See also: iterator.trace, iterator.map, iterator.force

    iterator:collect()¶

    Evaluates iterator, collecting all result values into a table.

    • If iterator has one return value per step, the resulting table will be list-like (i.e. keys from 1, 2, 3...).
    • If iterator has two or more return values per step, the resulting table will be map-like (i.e. keys from the first return value, values from the second return value). Note that all other arguments will be ignored.

    If you just want to evaluate iterator, and don't care about the results, use iterator:force() instead.

    Returns: table

    See also: iterator.force

    iterator:fold(acc, fn)¶

    Evaluates iterator, folding the return values into the accumulator acc using the folding function fn.

    On each step, fn is called like so: acc = fn(x, acc) (where x is the current value of iterator, and acc is the previously-returned value of acc).

    The result returned from fold is the final value of acc.

    In some sense, this is the opposite of Iter8.unfold.

    Parameters:

    Name Type
    acc A
    fn fun(x:T, acc: A): A

    Returns: A

    See also: iterator.fold1, Iter8.unfold

    iterator:fold1(fn)¶

    Evaluates iterator, folding the return values into the accumulator using the folding function fn.

    The accumulator is initialised with the first return value of the first step of iterator, and then the rest of the steps are folded in. This is useful for when you know that iterator contains at least one value, and you don't want to—or are unable to—provide a starting accumulator value.

    If iterator is empty, fold1 returns nil.

    See the documentation of fold for more information on how folding works.

    Parameters:

    Name Type
    fn fun(x:T, acc:A): A

    Returns: A

    See also: iterator.fold

    iterator:concat(sep)¶

    Evaluates iterator, returning the result of string-concatenating each value of iterator.

    An optional sep string is inserted between each element.

    Parameters:

    Name Type
    sep? string

    Returns: string

    iterator:any(pred)¶

    Evaluates iterator, returning true if pred returns true for at least one element. Short-circuits on the first matching element.

    Returns false for an empty iterator.

    Parameters:

    Name Type
    pred fun(...): boolean

    Returns: boolean

    See also: iterator.all

    iterator:all(pred)¶

    Evaluates iterator, returning true if pred returns true for every element. Short-circuits on the first non-matching element.

    Returns true for an empty iterator.

    Parameters:

    Name Type
    pred fun(...): boolean

    Returns: boolean

    See also: iterator.any

    iterator:find(pred)¶

    Evaluates iterator, returning the first element for which pred returns true, or nil if no element matches.

    Parameters:

    Name Type
    pred fun(...): boolean

    Returns: any

    iterator:min()¶

    Evaluates iterator, returning the minimum value. Returns nil for an empty iterator.

    Returns: any

    See also: iterator.max

    iterator:max()¶

    Evaluates iterator, returning the maximum value. Returns nil for an empty iterator.

    Returns: any

    See also: iterator.min

    iterator:count()¶

    Evaluates iterator, returning the number of steps of iterator.

    Returns: integer

    iterator:sum()¶

    Evaluates iterator, returning the numeric sum of each value of iterator.

    Returns: number

    iterator:nth(n)¶

    Evaluates iterator, returning the yielded values of the "nth" step of iterator.

    Like many things in Lua, nth is 1-based; i.e. iterator:nth(1) will return the first step of iterator.

    If n is greater than the number of steps of iterator, nth returns nil.

    Returns: any

    iterator:last()¶

    Evaluates iterator, returning the yielded values of the final step of iterator.

    If iterator is empty, last returns nil.

    Returns: any
